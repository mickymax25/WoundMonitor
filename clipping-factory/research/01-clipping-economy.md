# The TikTok Clipping Economy — Research Report (23 Aug 2026)
Flags: [V] vérifié presse mainstream/docs officiels ; [P] affirmations de la plateforme ; [U] invérifiable/marketing.

## 1. Marketplaces de campagnes payées
- **Whop "Content Rewards"** (hub de facto) : la marque finance une campagne au CPM (par 1 000 vues) ; clippers soumettent liens TikTok/Reels/Shorts/X ; approbation par la marque ; paiement sur budget séquestré ; seuil de paiement minimum + cap max par vidéo. Taux live **$0.20–$6/1k, moyenne ≈ $1** ; briefs premium jusqu'à $25/1k [P/U]. Budgets finis, premier arrivé premier servi. Échelle : Forbes (29 avr. 2026) : le marketplace de Daniel Bitton (18 ans) paie **>$40 000/jour sur ~1M vidéos/mois** ; clients Polymarket, ElevenLabs, Justin Bieber ; Whop valorisé $1.6B (invest Tether $200M, fév. 2026) [V]. Whop : ~100M vues clippées/jour, fee 9% [P]. Exemples : Iman Gadzhi $2/1k [P] ; Lovable AI $2/1k budget $10K [P] ; Polymarket $0.50/1k budget $70K [V, NPR].
- **Vyro** (MrBeast-backed, oct. 2025) : clips de MrBeast, Mark Rober… ; ~$3/1k ; paiement horaire, PayPal/crypto ; pas de minimum d'abonnés [V lancement, P taux] ; cap mensuel $1 000 selon un comparatif FR [U] ; une campagne a payé $100K [V]. Précurseur : MrBeast payait $50/100K vues [V].
- **Clipping.io** : >$1.5M payés revendiqués ; $1–3 CPM ; Stripe/PayPal [P].
- **ClipFarm** (Airrack, 2024, via Whop) [P]. ≠ clip.farm français.
- **JoinClips** : introuvable — non confirmé/défunt [U].
- **Kick Clipping Program** (la plateforme paie) : $40/100K vues, jusqu'à $50 ; 3B+ vues de clips/mois revendiquées [V/P].
- Repère presse : taux standard **$1–$5/1 000 vues vérifiées** avec caps [V, Digiday].

## 2. Créateurs qui paient ou autorisent officiellement
### Anglophone
- Iman Gadzhi (Whop $2/1k) [P] ; Kick (les streamers ne paient rien, Kick finance) [V] ; N3on ~$1M/mois aux clippers [U] ; MrBeast/Mark Rober via Vyro [V] ; Stake ~$100/post — @FearedBuck 64K→645K, comptes suspendus par X déc. 2024 [V] ; MLB clips $1/1k via agence [V, NPR] ; Cluely : 700+ clippers, 100M vues en semaines [V] ; campagnes politiques US 2024 des deux bords [V].
- **Gros podcasts (Rogan, Flagrant, IMPAULSIVE) : AUCUN programme officiel payé par les shows eux-mêmes trouvé** — clipping toléré/non autorisé ou financé par des marques via marketplaces [V absence].
### Francophone
- **Legend (Guillaume Pley) : AUCUN programme clippeur officiel trouvé** (recherches FR/EN août 2026). Legend distribue via ses propres comptes. Contexte : Legend sous forte pression médiatique août 2026 (enquêtes Le Monde/Les Inrocks sur le climat interne et la conduite de Pley ; plaintes en diffamation déposées par Pley) → lancement d'un programme public improbable à court terme [V absence].
- **clip.farm — Le Motif** (janv. 2025) : première vraie plateforme FR de clipping AUTORISÉ ; campagnes ouvertes par les créateurs ; seuil : 10 000 vues en 24h pour être payé, paiement proportionnel [V].
- **ByIlhann, Flamby** : autorisation publique de clipper (déc. 2024), sans paiement [V].
- **HugoDécrypte, Zack en Roue Libre, Sans Permis : aucun programme payé trouvé** ; HugoDécrypte a son short-form interne [V absence].
- Marketplaces/agences FR 2025-26 : **NF Clipping/Notify France** (€0.40/1k, cap €50/vidéo à 125K vues, ~70 clippers actifs, €2 142 payés au total déc. 2025–janv. 2026, top earner €728/2 mois) [P] ; **BeClipped** (escrow Stripe, 5–15% commission) [P] ; **Clipmax** (jusqu'à €3/1k, test d'entrée ; site partiellement hors ligne) [U] ; Agence Clipping, Postroyalty, NTHG [P]. Taux FR typiques : **€0.50–€2/1k — nettement sous les taux US** [P].
- Pushback FR : Nouvel Arc qualifie le clipping non autorisé de "vol de propriété intellectuelle" et demande à TikTok de réguler (janv. 2025) [V] ; presse pro FR le cadre comme illégal en droit d'auteur [V].

## 3. Monétisation TikTok (2026)
- **Creator Rewards** : 18+, 10K abonnés, 100K vues/30j, pays éligible (US, UK, DE, **FR**, JP, KR, BR, MX…). Seules les vidéos ORIGINALES >1 min avec ≥1 000 vues FYF qualifient ; duets/stitches/reposts watermarkés/diaporamas inéligibles [V]. "Reusing movie clips, podcasts, or others' footage with minor editing" disqualifié. Réaction avec commentaire substantiel PEUT passer ; les purs comptes clips non.
- **RPM** : US ≈ $0.40–$1.20/1k vues qualifiées (vues >5s seulement) ; **France ≈ €0.50–€0.70/1k** ; UK ≈ £1.30 ; DE ≈ €0.80 [P — estimations tierces, pas de RPM officiel].
- **TikTok Shop affiliate** (la vraie alternative pour comptes clips) : commissions open-collab 5–15% (moy. US ≈13%), collabs ciblées 15–25%, jusqu'à 50% ; **TikTok Shop est live en France** (commission plateforme 5% les 90 premiers jours puis 8%) [V/P].

## 4. Maths de revenus réalistes (vue sceptique)
- Cas vérifiés : un clipper ~$60 000 en 7 mois (~$8.6k/mois) [V, Digiday] ; Emrah Bayraktar (25, Anvers) : $12 → $2 500 en 2 semaines, dirige un réseau de 40 000 clippers + vend de la formation (conflit d'intérêts) [V] ; Bo Lucenko (19) ~$4 000/mois [V, NPR] ; agence d'Anthony Fujiwara ~$8M CA [V, Forbes].
- **Distribution ultra-Pareto** : médiane ~$24 gagnés au total ; <5% dépassent $100/mois ; ~1% dépassent $1 000/mois (communautés 6 000+) ; top 10% capte ~56% des payouts, bottom 50% se partage ~9% [U — plausible, non audité].
- Paliers répétés : débutants $0–80 le 1er mois / $200–500/mois ; opérateurs réguliers $500–3 000/mois ; "élite" $10–20K+/mois (auto-déclaré/marketing) [P/U]. Retainers élite : $500–1 500/mois garantis + performance [V].
- France : exemples travaillés NF Clipping — 1 vidéo/jour à ~5K vues moy. ≈ **€74/mois** ; haut performeur ≈ €294/mois ; €2 142 payés sur ~70 clippers en ~2 mois (≈€15/clipper/mois) [P — utilement dégonflant].
- Tempo des opérations qui marchent : 10–20 clips/jour multi-comptes [U] ; Cluely 700+ clippers ; démographie 16–24 ans [V]. Sanity check : à ~$1/1k, $2 000/mois = ~2M vues vérifiées/mois. Repère : side hustle US médian = $200/mois (Bankrate 2025) [V].
- Hype : "$500–$21 000/semaine" = quasi exclusivement vendeurs de formations [U].

## 5. 2025-2026 : fraude, crackdowns, saturation
- **Fraude aux vues structurelle** : cas documenté (campagne StreamAlive sur Whop) — vues clusterisées exactement au cap de paiement ; cap $100→$25, les vues "snappent" au nouveau cap = bots [V-ish]. Réponse Whop : détection renforcée, délai de paiement 24h, bans à vie [P].
- **L'argent gambling/crypto est un moteur majeur de la demande** (Stake, Polymarket, fintechs à $0.20–1/1k pour "inonder les feeds") ; Gambling Commission UK a forcé la sortie de Stake (fév. 2025) ; X a suspendu les comptes liés à Stake (déc. 2024) [V].
- **Pression de divulgation (US)** : clips payés = pubs ; disclosure FTC "doit voyager avec chaque post" [P]. (FR : loi influenceurs.)
- **Saturation** : taux en baisse au bas de gamme ($0.20–0.50/1k proliférants) ; budgets épuisés en heures ; presse mainstream (NPR, Longreads "The Clippening" mai 2026) décrit des feeds "envahis" ; la même donnée Pareto montre que la plupart des entrants ne gagnent ~rien. La demande s'élargit quand même (clients enterprise 2025 ; TBPN 37x plus de vues en clips qu'en live).
- **Marché FR en retard** : taux ~moitié des US, plateformes petites (dizaines de clippers), cadre légal (droit d'auteur, pas de fair use) → seuls les programmes AUTORISÉS (modèle clip.farm) sont défendables.

## Bottom line
Économie réelle et institutionnellement financée (Whop ~$40K/jour, programmes Kick/Vyro, couverture Forbes/NPR/Digiday), taux de marché $1–5/1k (FR €0.40–2). MAIS distribution extrêmement Pareto (médiane ≈ dizaines de dollars), Creator Rewards exclut les comptes clips, et la demande la mieux payée penche gambling/crypto/promo AI-startup avec friction croissante (fraude, disclosure, copyright). Aucun programme clippeur officiel pour Legend/Guillaume Pley ni les autres grands podcasts FR vérifiés ; l'équivalent FR le plus proche = clip.farm (Le Motif).
